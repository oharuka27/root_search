# よりみち

大阪市周辺の公園・喫茶店・猫カフェを、出発地と目的地の途中に提案するReact + 地図 + MCPアプリです。

## 起動

Node.js 22.12以上を推奨。

```sh
npm install
npm run dev
```

http://127.0.0.1:5173 を開いてください。ReactとMCPサーバーが同時に起動します。

```sh
npm run build
npm start
```

ビルド後は http://127.0.0.1:3001 で利用できます。ポートが変わるとブラウザの保存先オリジンも変わるため、開発版とビルド版の保存データは別です。

## 使い方

1. 出発地・目的地を選択。検索は収録済みの大阪の主要地点を対象にします。
2. 任意の住所は「住所指定」で名前・住所を入力し、地図または緯度・経度で位置を指定。
3. 公園・喫茶店・猫スポットと、滞在を含む追加時間を選択。
4. 「寄り道をさがす」を押すと、MCPを経由して候補を取得。
5. サンプルの喫茶店・猫カフェは架空です。実際の施設を探す場合は外部地図サービスを有効にし、「OpenStreetMapから取得」を選んで検索。
6. 候補を選択し、Google Mapsへのリンクから実際の徒歩道順を確認。

自宅・履歴・お気に入りはブラウザ内に保存します。同じブラウザプロファイルを共有する人とはデータも共有されるため、利用者ごとにプロファイルを分けてください。住所の自動ジオコーディングや道路経路計算はありません。所要時間と距離は概算です。

## MCP

エンドポイント `http://127.0.0.1:3001/mcp`、Streamable HTTP、ツール `find_spots`。公式SDKで接続・ツール呼び出しを実装しています。データ保存用サーバーはありません。

`OVERPASS_URL` で実データ取得先、`ALLOWED_ORIGINS`（カンマ区切り）で許可Originを変更できます。サーバーはローカル実行向けにHostを制限しています。

## 検証

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

詳しい構成とプライバシー上の境界は [docs/design.md](docs/design.md) を参照してください。

実データ接続も検証する場合は `RUN_LIVE=1 npm run test:e2e` を実行します。実行結果は [docs/verification.md](docs/verification.md) に記録しています。
